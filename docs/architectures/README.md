# econ-sae — model architectures, in n-orca

[econ-sae](https://github.com/jascal/econ-sae) trains SAEs over the hidden activations of small world-model MLPs that simulate a stock-flow-consistent macroeconomy. The non-LLM **world models** are documented first — their H1 hidden layer is the SAE training substrate. The three SAE variants follow.

Each entry has a verified [n-orca](https://github.com/jascal/n-orca) architecture document (`.n.orca.md`) and a Mermaid flowchart (`.mmd`). Regenerate with `python scripts/generate_sae_docs.py` from the n-orca repo, or call the `build_sae` / `build_world_model` tools on the registered `n-orca` MCP server.
